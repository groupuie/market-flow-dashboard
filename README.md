# astra-ledger:盤感測試帳

這個分支只放「Claude 盤感測試」的紀錄,和網站、📊量化 無關。

- **成績**:看 `summary.md`(每天收盤後自動更新)
- **規則**:`PROTOCOL.md`(事先寫死,測試期間不改)
- **每天的紀錄**:`pending/`(那天要判讀的買點和資料包)、`verdicts/`(Claude 的同意 / 不同意)、`marks.jsonl`(鎖定的總帳)、`scores.json`(每一點的結果)
- **試跑**:`test/`(不算成績)

白話:每天收盤後,網站的每個新「買」點,Claude 先寫「同意 / 不同意」並鎖住(GitHub 的時間戳記改不了),之後照網站賣法自動算對錯。
累積 300 筆後,如果 Claude 同意的那些點,勝率比全部的點高 10 個百分點以上,就建議網站只亮 Claude 同意的點。
