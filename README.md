# astra-ledger:盤感測試帳

這個分支只放「Claude 盤感測試」的紀錄,和網站、📊量化 無關。

- **成績**:看 `summary.md`(每天收盤後自動更新)
- **規則**:`PROTOCOL.md`(v2;事先寫死,和規則程式一起凍結在 `engine_manifest.json`;v1 在 `archive/v1/`,沒有正式筆)
- **每天的紀錄**:`batches/`(每個交易日一筆,含 0 個買點和失敗)、`pending/`(那天要判讀的買點和資料包)、`snap/`(被標記股票判讀時的 1,250 根日 K)、`verdicts/`(Claude 的同意 / 不同意)、`marks.jsonl`(鎖定的總帳)、`receipts/`(GitHub 的遠端收件時間)、`scores.json`(每一點的結果;賣出後不再改)、`cohort.json`(收案批次)、`look_ledger.json`(唯一一次判定)
- **試跑**:`test/`(不算成績)

白話:每天收盤後,網站的每個新「買」點,Claude 先寫「同意 / 不同意」並推上 GitHub(晚不晚以 GitHub 收到的時間為準,記在 `receipts/`),之後照網站賣法自動算對錯。
收案到 300 筆(同意、不同意各至少 60)就截止,等全部賣出後**只做一次**判定:同意的點扣成本後是不是真的比不同意的多賺(同一天、同一類型內比較),而且同意的勝率比全部高 10 個百分點以上。通過才建議網站只亮 Claude 同意的點,而且要使用者點頭。
