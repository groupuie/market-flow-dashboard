# 跌過頭就買 vs 等轉向(2026-10-15,Claude,只描述)

- 起因:使用者問 AI 股連跌一週(BE、NBIS)為什麼 Astra 沒有抄底 / 減碼
- `t1_turn_vs_early.py` → `t1_result.json`:266 檔、訊號日 2010-01 ~ 2026-07、賣法乙(頂 / −8% / 20 根)、每個買點各算一次、每邊 0.1%
  - 早買 = 當天超賣(RSI2 ≤ 10、收盤 ≤ 布林下緣、九轉買 9 任一),冷卻 5 根;▲底 = 近 3 天超賣 + 收盤 > 昨天最高(網站現行)
  - 急跌子集 = 訊號那天收盤比 6 根前低 ≥ 15%
- 結果(勝率 / 中位數 / 碰停損比例):
  - 全部:早買 54.4% / +0.81% / 25.7%;▲底 53.2% / +0.48% / 22.4% → 等轉向沒有比較準
  - 急跌:早買 41.1% / −6.46% / 54.0%;▲底 36.3% / −6.16% / 54.1% → 兩種都是一半以上碰停損、典型一筆賠 6%;早買的平均 +4.18% 主要來自 GME、SBET 等少數大反彈(去掉頭尾 1% 後 +1.51%)
- 限制:同一批看過的資料、事後描述,不是候選規則;「急跌後不買」若要上線,要另外預先登記、用新樣本測
- 試驗帳:CLAUDE-T1

## 2026-10-16 更正(Astra v0.7.2 附錄三 §七)
- 「等轉向沒有比較準」→ **這份描述樣本的勝率沒有顯示等轉向比較高**。早買和等轉向是各自的候選事件,日期、筆數、股票權重都不同,不是「同一個機會今天買 vs 等轉向才買」的配對比較,不能推成「等轉向沒有用」
- 「碰停損比例」→ **因停損出場的比例**(同一天先看頂)
- 急跌早買的平均 +4.18% 是真的算術平均,不能因為中位數難看就忽略;也不能拿它保證一次只買一兩檔就拿得到那幾筆大反彈
- 要比較兩種操作,要從同一批起始機會配對重播(另案)
