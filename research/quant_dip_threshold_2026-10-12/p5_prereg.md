# 預先登記:📊量化「抄底」的資金氣候門檻放寬(2026-10-12,先寫規則、commit 後才跑)

- 使用者 10/12 10:5x:「還是要看資金氣候,但是閾值可以放寬」
- 背景:現行門檻 = 資金氣候 ≥ 80%(scripts/flow_climate.py `TH["buy"]`)。過去一年 251 個交易日沒有一天超過 65%,抄底幾乎不會出現

## 1. 規則(只改門檻 X,其他照舊)
- 同 `scripts/flow_climate.py` 的 `fc_events`(= 網站 `fcSeriesJS` 的 buy):
  - 今天收盤站上 20 日線(昨天在線下),而且近 20 根 min(收盤 ÷ 50 日線 − 1) ≤ −10% → 一個「轉折」(冷卻 20 根,以轉折計)
  - 轉折當天 min ≤ −15%,而且資金氣候 ≥ X → 抄底
- 候選 X:0.80(現行)、0.65、0.50、0.35、0.20;參考:不看氣候(只描述)

## 2. 資料與衡量
- 日K:Yahoo 還原(263 檔追蹤股 + SPY、QQQ,同 swing_tune s4)
- 資金氣候:`scripts/flow_climate.py --dump-series`(2009-06 起;和 data/flow_climate.json 2020-06 起逐日相同)
- 隔天開盤買;贏 = 20 天 / 40 天後的收盤比買價高;中途套 = 40 天內最低曾比買價低 10%
- 平常 = 同組、同期間所有日子(同樣隔天開盤買)
- 分期(訊號日):前段 2010-01-01 ~ 2017-12-31、後段 2018-01-01 ~ 2026-07-31
- 分組:IDX、MAG7、NDX、ALL(`research/swing_tune_2026-10-12/groups.json`)

## 3. 決定規則
- X 通過 = 前段、後段都成立:
  - ALL:次數 ≥ 50,40 天贏的比例 ≥ 平常 + 3 點,20 天贏的比例 ≥ 平常
  - NDX:次數 ≥ 30 才看,40 天贏的比例 ≥ 平常
- 從 0.65 往下一個一個看(0.65 → 0.50 → 0.35 → 0.20);新門檻 = 連續通過的最後一個(中間有一個沒過就停在前一個)
- 0.65 就沒過 → 不放寬,維持 0.80,回報使用者

## 4. 只描述
- 每個 X:最近一年(2025-10-10 ~ 2026-10-09)全部追蹤股會出現幾個抄底
- 選定的 X:強(大盤 QQQ 離一年高點 ≥10%)/ 照舊(VIX ≥ 20)/ 弱 的 20 天勝率(後段;網站滑過用),以及 `STATS.buy` 的數字(前段、後段、AI 子集)
