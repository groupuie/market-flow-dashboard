## 2. 判讀者與記憶
- 每 2 回合換一個全新的 Claude(共 105 個);只准 Read(那幾回合的資料包、圖、錯誤說明)和 Write(答案)
- 記憶:型態筆記(每回合整份重寫,2,500 字內)+ 累積成績(伺服器算);筆記起點只有上兩輪的通則(沒有任何日期、價格)
- 每格的答案:call(buy / sell / wait)、pb、ps(現在買 / 賣會「對」的機率 0–100,每格都要給)、buy / sell 另附 why、days;rec = 覺得認得出是哪一檔 / 哪一段的格子

## 3. 一段的定義(每張圖的答案)
- ATR20 = 決定日以前 20 天的平均真實波幅 ÷ 收盤
- 買:之後第 1–10 個交易日,盤中最高先到「收盤 ×(1 + 2×ATR20)」→ 對;盤中最低先到「收盤 ×(1 − 1.5×ATR20)」→ 洗;同一天都到 → 洗;都沒到 → 沒。賣:鏡像(先跌 2×ATR20 → 對;先漲 1.5×ATR20 → 軋)
- 同檔基準:同一檔、決定日前後各 10 個交易日(只用同一期:訓練用訓練期、考試用考試期)隨便哪一天的「對」比例

## 4. 主要檢查(考試集 1,440 張;跑之前寫死)
- **H1 買點**:pb 對「買對」的 AUC;區間 = 以決定日(日期叢集)重抽 4,000 次(seed 20261017)的 95% 區間。下界 > 0.5 → 有分辨力;區間含 0.5 → 沒有證據;上界 < 0.5 → 反向
- **H2 賣點**:ps 對「賣對」的 AUC,同上
- 考試集少於 50 張答過的 → 資訊不足

## 5. 次要(只描述)
- 下單的買點 / 賣點:對的比例 − 同檔前後 10 天基準,以日期重抽 4,000 次;≥ 30 筆才判定(下界 > 0 有盤感 / 上界 < 0 比隨便差 / 跨 0 沒有證據)
- pb 最高一成的實際買對比例對同檔基準;校準表;各型態(整理 / 拉回 / 急跌 / 其他)的 AUC;買對的平均第幾天、洗盤深度
- 學習曲線:全部回合分 5 段的 AUC(全部與考試);考試集前半 / 後半的 AUC
- 訓練集(可能有記憶)的 AUC 只描述;各年份 AUC;判讀者說「認得」的張數與其 AUC(污染監測)
