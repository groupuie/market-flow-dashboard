# 布林上軌 + 長上影線 → 之後下跌?(2026-10-09 使用者直覺檢驗)

規則:當日最高價 ≥ 布林上軌(20 日、2 倍標準差,與前端 bbands 同口徑),且上影線佔整根 K 棒(高−低)≥ 1/4、1/3、1/2、2/3。
資料:259 檔個股 2007–2026(Yahoo 調整後日K)、10 檔指數/板塊 ETF 1999–2026。收盤進場與隔日開盤進場兩種;日期區塊自助法 CI。

結論:
- 個股:≈ 擲硬幣。5 日後下跌機率 2007–17 為 47.3–47.6%(平常 45.7%)、2018–26 為 46.5–46.7%(平常 46.8%);平均報酬反而略正。
  上影比例拉高、黑K、收回軌內、爆量、隔天收破低點確認、AI 子集、搭配資金氣候 — 都沒有改善。
  「碰上軌但收在最高(沒上影)」的下跌機率不比長上影低。唯一有一點資訊的是「漲離 50 日線多遠」,上影線沒有額外加分。
- 指數/板塊 ETF:5 日後下跌機率高 3–6 個百分點(1999–2012:51.0% vs 44.6%;2013–2026:44.7% vs 41.3%),但大部分來自「指數碰上軌」本身(無長上影也有 49.6% / 43.3%),上影線只多 1–2 點。
- 頻率:上影 ≥1/4 每檔每年約 18 次、≥1/3 約 14 次、≥1/2 約 7 次 — 太常見,不可能有大優勢。

## 追問:上影線要配合什麼條件才準?(同日 2026-10-09)
- `tops_wick.py`:真高點(±10日最高、之後20日內跌≥10%)當天有 ≥1/4 上影 60%(一般日子 46%);高點±1天內 82%(隨便連續3天 84%)。
  反過來,碰上軌+長上影的日子落在真高點±2天內 21%,與「任何碰上軌的日子」相同 → 高點多有上影,但上影多半不是高點。
- `wick_cond.py`:16 個單一條件 + 14 個組合,「有上影 vs 同條件無上影」兩期皆無一致差異;條件本身(拉離50日線、前5日漲幅、爆量、氣候)才有資訊。
- `wick_ml.py`:梯度提升樹在碰上軌日自己找組合,樣本外分辨力含上影 0.687 / 不含 0.683(真高點)、0.620 / 0.620(10日跌>3%)。
- `wick_rev.py`:「收盤離當日高點≥5%」「當天收跌≥3%」略偏空(+3~5 點),平均報酬仍正。
- `wick_trim*.py`(有用的用法):把上影當「先行警示」——技判「出」/▼ 之前 10 日內出現過「碰上軌+上影≥1/4」:
  出:40日後較低 +4.9 點 [90% CI +2.2, +7.5]、40日內跌≥10% +8.4 點 [+5.6, +11.2];
  ▼:40日後較低 +6.2 點 [+1.6, +10.4]、40日平均 −3.7% [−6.2, −1.1](有前置上影 58%/−5.0% vs 沒有 52%/−1.3%)。
  5–10 日看不出差別 → 上影線告訴你「可能是波段頂」,不是「明天會跌」;賣點仍是之後的收破 20 日線。

## 再追問:要「至少賣在高點隔天」,還有什麼條件能補強?(`sellnext*.py`)
嚴格成功定義:賣出後 20 日內最高價沒有超過訊號K最高價 2% 以上(頂已出現),且從賣價再跌 ≥8%。基準:任何一天 17%、碰上軌+上影≥1/4 18%。
- 最重要:把「上影佔K棒幾分之幾」換成「收盤離當天最高跌了幾 %」(≥5%:成功率 31–33%,約 2 倍)。
- 漲多前提(20 日漲 ≥30%、高於 20 日線 ≥3 倍 ATR、或高於 50 日線 ≥25%,任一)再加分。
- 隔天確認(隔天收盤跌破這根K的最低價 → 隔天收盤賣)把成功率再拉高約 15 點。
- 「頂K」= 漲多 + 碰上軌 + 收盤離最高 ≥5% → 隔天收破低點賣:2007–16 50% [41,60]、2017–26 47% [41,52];40日後較低 56–58%(平常 41–43%)。
  × 資金氣候 ≤35%:57%(兩期),40日後較低 67–71%,40日平均 −8%~−11%。AI 子集較弱(2017–26 39%;AI 狂熱期多次賣早)。
  只用 2007–16 選參數、2017–26 驗證:48–50%(基準 18%)。
- 沒幫助:上影比例門檻、爆量(單獨)、黑K、大盤/費半同步上影、RSI、TD賣9、M頭。
- 價格面:賣價中位比近 10 日最高收盤低 10.7%(技判「出」10.6%)→ 時間上早(高點隔天),價格上與「出」相近(急漲急跌型頂)。

## 三追問:為什麼不當晚就賣?(`samenight*.py`,同日)
同一批頂K(漲多 + 碰上軌 + 收盤離當日高點 ≥5%),兩期 2009–16 / 2017–26;「與續抱比」= log(賣價 ÷ 第 h 日收盤),正 = 賣得好;CI 為 20 日區塊自助法 90%。
- **A 當晚收盤賣**:每檔每年 0.34 / 1.40 次;賣在頂(20 日嚴格定義)33% / 30%(基準 17%);賣價比近 10 日最高收盤只低 1.2% / 1.6%。
- **B 等隔天收破這根K最低價**:只有 24% / 29% 的頂K 會被確認;賣在頂 49% / 47%;賣價低 10.1% / 10.7%。
- 40 日後:A 股價比賣價低 48% / 53%、中位數賣得好 −1.2% / +2.7%;B(只算有賣的)55% / 56%、+3.3% / +4.6%。
  兩邊尾巴都很胖:A 之後再漲 ≥40% 15% / 21%、再跌 ≥20% 19% / 31%;B 再漲 ≥40% 17% / 20% → 確認不會消除「錯過大段」。
  與續抱比的平均:A −2.6% [−9.1,+3.9] / −1.7% [−7.1,+3.7];B(沒確認=不賣=0)−0.1% / −0.6% → 兩者都≈打平。
  (簡單報酬算術平均被少數翻倍股拉到 −8% / −17%,所以全部當晚賣在「錢」上不划算。)
- **I 盤中一離今日高點 5% 就賣**(昨收已漲多 + 碰上軌,假設先高後低 → 次數上限):次數 ×3.6 / ×2.7,賣在頂 25% / 22%。
  多出來的「盤中跌 5% 但收盤拉回 > 高點×0.95」日子:20 日 −3.2% [−5.9,−0.3] / −4.6% [−7.3,−1.8](兩期 CI 都不含 0,賣早 35% / 39%)
  → 當晚賣要看「接近收盤時仍離高點 ≥5%」,不是盤中第一次跌破。真成形的那批若在高點×0.95 賣,賣價比收盤高約 5%(但盤中無法分辨)。
- 資金氣候:A 兩期方向相反(≤35%:−5.5% n=101 / +11.6% [+3.7,+18.0];>35%:+3.1% / −6.2%)→ 不能當依據;B ≤35% 兩期皆正(+1.3%〔確認僅 14 筆〕/ +3.2% [+0.8,+5.6])。
- AI 股:A 兩期都賣早(40 日 −7.7% / −7.9%,40 日後比賣價低只有 38% / 45%);B −0.1% / −2.7%。
- 一半當晚、一半等確認:平均 −1.4% / −1.2%(=兩者平均),不會讓平均變好,只是讓「賣早」與「賣晚」兩種後悔各減半。
- 結論:當晚賣可行、價格好很多(≈高點附近),代價是「真頂」機率從 ~1/2 降到 ~1/3;頂K 之後兩邊都可能大走(3 成再跌 ≥20%、2 成再漲 ≥40%)→ 適合分批,不適合一次全賣;AI 強勢股當晚賣歷史上偏賣早。
